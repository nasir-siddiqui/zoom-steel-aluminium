# Zoom Steel Aluminium

Premium single-page business website for **Zoom Steel Aluminium**, a steel fabrication and aluminium works company serving Mumbai.

## 🌐 Live Website

**Live Demo:**  
https://zoom-steel-aluminium.vercel.app/page-2.html

## 🚀 Project Overview

This project is a responsive, single-page marketing website designed to showcase:

- Steel fabrication services
- Aluminium works
- Main gates
- Railings and grills
- Glass work
- Pergolas
- Parking sheds
- Residential and commercial projects

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- SVG
- HTML5 Canvas
- Intersection Observer API
- Schema.org JSON-LD
- Google Fonts
